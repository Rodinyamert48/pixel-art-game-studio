## نظرة عامة

‏Pixel Art Game Studio هو مهارة (skill) لـ Claude Code مع فريق من ثمانية وكلاء فرعيين متخصصين، الغرض منه
بناء ألعاب أصلية ثنائية الأبعاد بأسلوب فن البكسل. أنت تصف اللعبة التي تتخيلها، وما لا يعجبك في النتيجة
الحالية، وما الذي ينبغي تغييره بعد ذلك. ويتولى Claude تخطيط العمل وكتابة الشيفرة وتوليد الرسومات وتشغيل
الاختبارات وإصلاح الأخطاء التي يمكن إعادة إنتاجها، ولا يبلّغ إلا عمّا تحقّق منه فعلًا.

صُممت الأداة لمغامرات القصص الهادئة، ومحاكيات الحياة والمزارع، وألعاب تقمّص الأدوار الغنية بالحوار، وألعاب
الاستكشاف ذات المنظور العلوي، وألعاب الألغاز، ويمكن استخدامها أيضًا لأفكار أصلية أخرى ثنائية الأبعاد. وتبقى
أربعة أجزاء منفصلة: **المهارة** (التعليمات)، و**الوكلاء** (المتخصصون)، و**السكربتات** (أدوات حتمية تعطي
النتيجة نفسها دائمًا)، و**لعبتك** (في مجلد مشروع مستقل).

<!-- section: features -->
## الميزات

- سير عمل Game Director الذي يحوّل فكرة غير محددة إلى تصميم قصير وحلقة لعب دنيا قابلة للتجربة.
- ثمانية متخصصين لكل منهم مسؤولية واضحة وقائمة أدوات محدودة وتقارير ذات بنية ثابتة.
- فن بكسل إجرائي: تتحول مواصفات JSON إلى أوراق رسوم PNG حقيقية وبيانات وصفية ومعاينات. والمواصفة نفسها
  تنتج البايتات نفسها دائمًا.
- عقد بيانات للخرائط والزخارف والحوارات والمهام والعناصر والترجمات، مع أداة تحقق تكشف المخارج التي لا يمكن
  الوصول إليها وفروع الحوار المستحيلة ومفاتيح النصوص المفقودة.
- ضمان جودة يتضمن مستويات خطورة وتقارير أخطاء قابلة لإعادة الإنتاج وإصلاحات مؤكدة باختبارات انحدار.
- مثبّت آمن يدعم التشغيل التجريبي واكتشاف التعارضات والنسخ الاحتياطية والإزالة الحذرة.

## فريق الوكلاء

هناك تسعة أدوار. **Game Director** هو المهارة نفسها، ويعمل في جلستك الرئيسية في Claude Code: يحفظ التصميم،
ويكتب أوصاف المهام، ويفحص كل نتيجة، ويقرّر متى يكتمل العمل. أما الوكلاء الفرعيون الثمانية فهم:

| الوكيل | المسؤولية |
| --- | --- |
| `pixel-artist` | التوجيه الفني ومواصفات الأصول والرسوم والبلاطات المولّدة |
| `npc-story-engineer` | الشخصيات والحوارات المتفرعة والعلامات والمهام |
| `world-builder-level-design` | بنية الخرائط والتصادم ونقاط الظهور والمخارج |
| `world-builder-environmental-content` | الزخارف والأماكن المثيرة للاهتمام وأجواء كل منطقة |
| `ui-engineer` | القوائم وواجهة العرض ونافذة الحوار وشاشات المخزون والحفظ |
| `gameplay-engineer` | الحركة وحالة اللعبة والمخزون والمهام والحفظ |
| `qa-tester` | الاختبارات وتشغيلها وتقارير الأخطاء |
| `bug-fixer` | إصلاح الأسباب الجذرية مع اختبارات الانحدار |

مزيد من التفاصيل في [AGENTS.md](../AGENTS.md).

## البنية

الـ Director مهارة وليس وكيلًا فرعيًا، لأنه يحتاج إلى رؤية طلباتك والحفاظ على مصدر واحد للحقيقة
(`design/GAME_DESIGN.md` و`ART_DIRECTION.md` وخمس وثائق قصيرة أخرى). يتلقى المتخصصون أوصافًا محددة للمهام،
ويعملون على الملفات التي يملكونها فقط، ثم يعيدون تقريرًا؛ ولا يمكنهم تشغيل وكلاء آخرين. ويُحفظ محتوى اللعبة
في مجلد `data/` المستقل عن المحرك، بحيث يمكن العمل على القصة والمستويات والبيئة بالتوازي والتحقق منها دون
تشغيل المحرك. وإذا لم يكن الوكلاء الفرعيون متاحين، ينفّذ الـ Director الخطوات نفسها بنفسه، واحدة تلو الأخرى.
راجع [ARCHITECTURE.md](../ARCHITECTURE.md).

<!-- section: prerequisites -->
## المتطلبات المسبقة

- ‏Claude Code (جرى التحقق باستخدام الإصدار 2.1.312).
- ‏Python 3.9 أو أحدث؛ لا حاجة إلى حزم إضافية.
- للألعاب الحقيقية، المحرك الذي تختاره، مثل Godot 4 أو .NET SDK لـ MonoGame. تتحقق المهارة مما هو مثبّت
  وتطلب إذنك قبل تثبيت أي شيء.

<!-- section: installation -->
## التثبيت

أسهل طريقة هي تثبيتها كإضافة (plugin) من داخل Claude Code. وعندئذٍ تُستدعى المهارة باسم `/pixel-art-game-studio:pixel-art-game-studio`، وتحمل أسماء الوكلاء البادئة `pixel-art-game-studio:`:

</div>

```text
/plugin marketplace add Rodinyamert48/pixel-art-game-studio
/plugin install pixel-art-game-studio@pixel-art-game-studio
```

<div dir="rtl">

أو من دون نظام الإضافات:

انسخ المستودع، ثم اختر طريقة التثبيت. استعرض كل تغيير أولًا باستخدام `--dry-run`:

</div>

```bash
python scripts/install.py --scope project --project-dir ../my-game --dry-run
python scripts/install.py --scope project --project-dir ../my-game
python scripts/install.py --scope user
```

<div dir="rtl">

يكتب نطاق المشروع إلى `<project>/.claude/`، ويكتب نطاق المستخدم إلى `~/.claude/`. ولا تُستبدل أبدًا الملفات
الموجودة التي لم ينشئها المثبّت. استخدم `--update` لتحديث التثبيت (مع نسخ احتياطي للملفات القديمة)، و`--uninstall`
لإزالة الملفات التي ثبّتها فقط ولم تتغير. ويمكنك أيضًا تشغيل Claude Code مباشرة داخل هذا المستودع أو نسخ
المجلدات يدويًا. جميع الخيارات موجودة في [INSTALLATION.md](../INSTALLATION.md).

<!-- section: quick-start -->
## البدء السريع

افتح Claude Code في مجلد مشروعك واكتب:

</div>

```text
/pixel-art-game-studio أنشئ لعبة أصلية هادئة بفن البكسل ومنظور علوي، فيها بلدة صغيرة وغابة وثلاث شخصيات وحوارات متفرعة ودورة نهار وليل ونظام حفظ.
```

<div dir="rtl">

يختار الـ Director قيمًا افتراضية معقولة، ويكتب تصميمًا قصيرًا، ويبني أولًا نسخة صغيرة قابلة للعب. ولاستدعاء
متخصص واحد مباشرة، اذكر اسمه، مثل `@agent-qa-tester`.

## أمثلة على الطلبات

<!-- section: workflows -->
## مسارات العمل

- **إنشاء لعبة**: من الفكرة إلى التسليم في 14 مرحلة، بدءًا بحلقة لعب دنيا.
- **توسيع لعبة**: فحص المشروع الحالي، وإجراء أصغر تغيير متماسك، والتحقق من عدم حدوث تراجع.
- **الاختبار والإصلاح**: تشغيل اختبارات حقيقية، والإبلاغ عن الأخطاء، وإصلاح المؤكد منها بعدد محدود من
  المحاولات.
- **توليد الأصول**: التوجيه الفني أولًا، ثم المواصفات وملفات PNG والمعاينات.
- **فحص الإصدار**: حكم مدعوم بالأدلة: جاهز، أو جاهز مع مشكلات معروفة، أو غير جاهز.

نظرة عامة في [WORKFLOWS.md](../WORKFLOWS.md).

## الاختبار وإصلاح الأخطاء

يكتشف مختبِر الجودة الأدوات التي تملكها اللعبة فعلًا، ويحوّل معايير القبول إلى اختبارات، ويشغّلها، ثم يكتب
تقارير أخطاء تتضمن الخطورة والخطوات والأدلة. ويعيد مُصلح الأخطاء إنتاج كل خطأ، ويعالج السبب الجذري، ويضيف
اختبار انحدار، ثم يعيد تشغيل الفحوص. ولا يُسمح أبدًا بإضعاف الاختبارات أو حذفها. لاختبار هذا المستودع نفسه:

</div>

```bash
python -m unittest discover -s tests -v
python scripts/validate_repository.py
```

<div dir="rtl">

التفاصيل في [TESTING.md](../TESTING.md).

<!-- section: limitations -->
## القيود

- لا تنشئ الأداة وحدها ألعابًا تجارية مكتملة؛ توقّع أساسًا يعمل وينمو مع ملاحظاتك.
- عند عدم تثبيت محرك، لا يمكن التحقق إلا من البيانات والأصول والمنطق الذي لا يعتمد على المحرك.
- لا تستطيع الفحوص البنيوية الحكم على جمال الرسوم أو متعة اللعبة؛ فذلك يحتاج إلى إنسان.
- الترجمات منجزة بمساعدة الآلة وهي بانتظار مراجعة المتحدثين الأصليين.

## استكشاف الأخطاء وإصلاحها

إذا لم تظهر المهارة، فتأكد من أن الملف `SKILL.md` موجود في `.claude/skills/pixel-art-game-studio/`. وإذا لم
يُعثر على الوكلاء، فأعد تشغيل Claude Code بعد إنشاء `.claude/agents/`. وإذا انتهى المثبّت بالرمز 2، فهذا يعني
أنه وجد ملفًا لم ينشئه؛ اقرأ الخطة التي عرضها. ستجد إجابات أخرى في [TROUBLESHOOTING.md](../TROUBLESHOOTING.md).
