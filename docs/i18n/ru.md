# Pixel Art Game Studio

[← Основной README](../../README.md) · Русский · Перевод выполнен с помощью машинного перевода и ожидает проверки носителями языка.

<!-- section: overview -->
## Обзор

Pixel Art Game Studio — это навык (skill) для Claude Code и команда из восьми специализированных
субагентов для создания оригинальных 2D-игр в стиле пиксель-арт. Вы описываете игру, которую
представляете, что вам не нравится в текущем результате и что нужно изменить дальше. Claude планирует
работу, пишет код, создаёт графику, запускает тесты, исправляет ошибки, которые удаётся воспроизвести,
и сообщает только о том, что действительно проверил.

Инструмент рассчитан на уютные сюжетные приключения, симуляторы жизни и фермы, ролевые игры с большим
количеством диалогов, исследовательские игры с видом сверху и головоломки, но подходит и для других
оригинальных 2D-идей. Четыре части разделены: **навык** (инструкции), **агенты** (специалисты),
**скрипты** (детерминированные инструменты) и **ваша игра** (отдельный каталог проекта).

<!-- section: features -->
## Возможности

- Процесс Game Director, который превращает размытую идею в короткий дизайн и минимальный играбельный
  цикл.
- Восемь специалистов с чёткими зонами ответственности, ограниченными наборами инструментов и
  структурированными отчётами.
- Процедурный пиксель-арт: JSON-описания превращаются в настоящие PNG-листы спрайтов, метаданные и
  превью. Одно и то же описание всегда даёт одни и те же байты.
- Контракт данных для карт, декора, диалогов, заданий, предметов и переводов, а также валидатор,
  который находит недостижимые выходы, невозможные ветки диалогов и отсутствующие текстовые ключи.
- Контроль качества с уровнями серьёзности, воспроизводимыми отчётами о дефектах и проверенными
  исправлениями с регрессионными тестами.
- Безопасный установщик с пробным запуском, обнаружением конфликтов, резервными копиями и аккуратным
  удалением.

<!-- section: agents -->
## Команда агентов

Ролей девять. **Game Director** — это сам навык, он работает в вашей основной сессии Claude Code:
ведёт дизайн, пишет задания, проверяет каждый результат и решает, когда работа завершена. Восемь
субагентов:

| Агент | Ответственность |
| --- | --- |
| `pixel-artist` | арт-дирекшн, описания ассетов, сгенерированные спрайты и тайлы |
| `npc-story-engineer` | персонажи, ветвящиеся диалоги, флаги, задания |
| `world-builder-level-design` | структура карт, столкновения, точки появления, выходы |
| `world-builder-environmental-content` | декор, интересные места, атмосфера регионов |
| `ui-engineer` | меню, HUD, окно диалога, экраны инвентаря и сохранения |
| `gameplay-engineer` | передвижение, состояние игры, инвентарь, задания, сохранение |
| `qa-tester` | тесты, запуск тестов, отчёты о дефектах |
| `bug-fixer` | исправление первопричин с регрессионными тестами |

Подробнее: [AGENTS.md](../AGENTS.md).

<!-- section: architecture -->
## Архитектура

Director — это навык, а не субагент, потому что он должен видеть ваши запросы и вести единый источник
истины (`design/GAME_DESIGN.md`, `ART_DIRECTION.md` и ещё пять коротких документов). Специалисты
получают задания, работают только со своими файлами и возвращают отчёт; запускать других агентов они
не могут. Игровой контент хранится в независимой от движка папке `data/`, поэтому сюжет, уровни и
окружение можно делать параллельно и проверять без запуска движка. Если субагенты недоступны, Director
выполняет те же шаги сам, по очереди. См. [ARCHITECTURE.md](../ARCHITECTURE.md).

<!-- section: prerequisites -->
## Требования

- Claude Code (проверено на версии 2.1.312).
- Python 3.9 или новее; дополнительные пакеты не нужны.
- Для настоящих игр — выбранный вами движок, например Godot 4 или .NET SDK для MonoGame. Навык
  проверяет, что установлено, и спрашивает разрешения, прежде чем что-либо устанавливать.

<!-- section: installation -->
## Установка

Клонируйте репозиторий и выберите способ установки. Сначала просмотрите изменения с `--dry-run`:

```bash
python scripts/install.py --scope project --project-dir ../my-game --dry-run
python scripts/install.py --scope project --project-dir ../my-game
python scripts/install.py --scope user
```

Область проекта записывает файлы в `<project>/.claude/`, пользовательская область — в `~/.claude/`.
Существующие файлы, которые создал не установщик, никогда не заменяются. Используйте `--update`, чтобы
обновить установку (старые файлы сохраняются в резервную копию), и `--uninstall`, чтобы удалить только
неизменённые файлы, установленные им самим. Можно также запустить Claude Code прямо в этом репозитории
или скопировать папки вручную. Все варианты описаны в [INSTALLATION.md](../INSTALLATION.md).

<!-- section: quick-start -->
## Быстрый старт

Откройте Claude Code в папке проекта и введите:

```text
/pixel-art-game-studio Создай оригинальную уютную пиксельную игру с видом сверху: небольшой город, лес, три NPC, ветвящиеся диалоги, смена дня и ночи и сохранение.
```

Director выберет разумные значения по умолчанию, напишет короткий дизайн и сначала соберёт небольшую
играбельную версию. Чтобы вызвать одного специалиста напрямую, упомяните его, например
`@agent-qa-tester`.

<!-- section: examples -->
## Примеры запросов

```text
/pixel-art-game-studio Добавь туманное болото с двумя NPC и заданием с двумя концовками.
/pixel-art-game-studio Город выглядит пустым. Добавь детали и небольшие находки, но оставь дороги свободными.
/pixel-art-game-studio Изучи эту игру, запусти все доступные тесты и исправь воспроизводимые ошибки.
```

Запросы можно писать на любом языке. Полный пример есть в [examples](../../examples/example-game-idea.md).

<!-- section: workflows -->
## Рабочие процессы

- **Создание игры**: от идеи до сдачи за 14 этапов, начиная с минимального играбельного цикла.
- **Расширение игры**: изучить существующий проект, внести наименьшее связное изменение, проверить
  отсутствие регрессий.
- **Тестирование и исправление**: запускать настоящие тесты, сообщать о дефектах, исправлять
  подтверждённые с ограниченным числом попыток.
- **Создание ассетов**: сначала арт-дирекшн, затем описания, PNG-файлы и превью.
- **Проверка перед релизом**: вердикт, подкреплённый доказательствами: готово, готово с известными
  проблемами или не готово.

Обзор: [WORKFLOWS.md](../WORKFLOWS.md).

<!-- section: testing -->
## Тестирование и исправление ошибок

Тестировщик QA выясняет, какие инструменты действительно есть у игры, превращает критерии приёмки в
тесты, запускает их и пишет отчёты о дефектах с серьёзностью, шагами и доказательствами. Исправитель
ошибок воспроизводит каждый дефект, устраняет первопричину, добавляет регрессионный тест и снова
запускает проверки. Ослаблять или удалять тесты запрещено. Чтобы проверить сам репозиторий:

```bash
python -m unittest discover -s tests -v
python scripts/validate_repository.py
```

Подробнее: [TESTING.md](../TESTING.md).

<!-- section: limitations -->
## Ограничения

- Инструмент сам по себе не создаёт готовые коммерческие игры; ожидайте рабочую основу, которая растёт
  вместе с вашими отзывами.
- Без установленного движка можно проверить только данные, ассеты и логику, не зависящую от движка.
- Структурные проверки не могут оценить, красива ли графика и интересна ли игра; для этого нужен
  человек.
- Переводы выполнены с помощью машинного перевода и ждут проверки носителями языка.

<!-- section: troubleshooting -->
## Устранение неполадок

Если навык не появляется, проверьте, что `SKILL.md` лежит в `.claude/skills/pixel-art-game-studio/`.
Если агенты не находятся, перезапустите Claude Code после создания `.claude/agents/`. Если установщик
завершился с кодом 2, он нашёл файл, который создал не он; прочитайте выведенный план. Другие ответы — в
[TROUBLESHOOTING.md](../TROUBLESHOOTING.md).
