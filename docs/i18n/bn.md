# Pixel Art Game Studio

[← মূল README-তে ফিরুন](../../README.md) · বাংলা · এই অনুবাদটি যন্ত্রের সহায়তায় তৈরি এবং মাতৃভাষী পর্যালোচনার অপেক্ষায় আছে।

<!-- section: overview -->
## পরিচিতি

Pixel Art Game Studio হলো Claude Code-এর জন্য একটি স্কিল (skill), যার সঙ্গে আছে আটটি বিশেষজ্ঞ
সাবএজেন্টের একটি দল। এর কাজ হলো মৌলিক 2D পিক্সেল-আর্ট গেম তৈরি করা। আপনি শুধু বলবেন কোন গেমটি
আপনি কল্পনা করছেন, বর্তমান ফলাফলে কী আপনার পছন্দ হচ্ছে না এবং এরপর কী বদলাতে হবে। Claude কাজের
পরিকল্পনা করে, কোড লেখে, গ্রাফিক্স তৈরি করে, টেস্ট চালায়, যেসব ত্রুটি আবার ঘটানো যায় সেগুলো ঠিক
করে এবং শুধু সেটুকুই জানায় যা সে সত্যিই যাচাই করেছে।

এটি আরামদায়ক গল্পনির্ভর অভিযান, জীবন ও খামারের সিমুলেশন, সংলাপপ্রধান RPG, ওপর থেকে দেখা অনুসন্ধানের
গেম এবং ধাঁধার গেমের জন্য তৈরি, তবে অন্য মৌলিক 2D ভাবনার জন্যও কাজে লাগে। চারটি অংশ আলাদা রাখা
হয়: **স্কিল** (নির্দেশনা), **এজেন্ট** (বিশেষজ্ঞ), **স্ক্রিপ্ট** (সবসময় একই ফল দেয় এমন টুল) এবং
**আপনার গেম** (এর নিজস্ব প্রজেক্ট ডিরেক্টরি)।

## বৈশিষ্ট্য

- Game Director-এর কর্মপদ্ধতি, যা একটি অস্পষ্ট ভাবনাকে ছোট একটি ডিজাইন এবং খেলার উপযোগী সবচেয়ে
  ছোট একটি লুপে পরিণত করে।
- আটজন বিশেষজ্ঞ, যাদের দায়িত্ব স্পষ্ট, টুলের তালিকা সীমিত এবং রিপোর্টের কাঠামো নির্দিষ্ট।
- প্রসিডিউরাল পিক্সেল আর্ট: JSON বিবরণ থেকে আসল PNG স্প্রাইট শিট, মেটাডেটা এবং প্রিভিউ তৈরি হয়।
  একই বিবরণ থেকে সবসময় একই বাইট তৈরি হয়।
- মানচিত্র, সাজসজ্জা, সংলাপ, কোয়েস্ট, জিনিসপত্র ও অনুবাদের জন্য একটি ডেটা চুক্তি এবং একটি
  ভ্যালিডেটর, যা পৌঁছানো যায় না এমন প্রস্থানপথ, অসম্ভব সংলাপ-শাখা এবং হারিয়ে যাওয়া টেক্সট কী খুঁজে
  বের করে।
- মান নিয়ন্ত্রণ, যাতে আছে গুরুত্বের স্তর, পুনরাবৃত্তিযোগ্য ত্রুটি রিপোর্ট এবং রিগ্রেশন টেস্ট দিয়ে
  যাচাই করা সংশোধন।
- একটি নিরাপদ ইনস্টলার, যাতে আছে ড্রাই রান, সংঘাত শনাক্তকরণ, ব্যাকআপ এবং সতর্কভাবে মুছে ফেলার
  ব্যবস্থা।

## এজেন্ট দল

মোট নয়টি ভূমিকা আছে। **Game Director** নিজেই স্কিল এবং আপনার মূল Claude Code সেশনে চলে: এটি
ডিজাইন রক্ষা করে, কাজের বিবরণ লেখে, প্রতিটি ফলাফল পরীক্ষা করে এবং ঠিক করে কখন কাজ শেষ। আটটি
সাবএজেন্ট হলো:

| এজেন্ট | দায়িত্ব |
| --- | --- |
| `pixel-artist` | শিল্প নির্দেশনা, অ্যাসেটের বিবরণ, তৈরি করা স্প্রাইট ও টাইল |
| `npc-story-engineer` | চরিত্র, শাখাযুক্ত সংলাপ, ফ্ল্যাগ, কোয়েস্ট |
| `world-builder-level-design` | মানচিত্রের গঠন, সংঘর্ষ, শুরুর জায়গা, প্রস্থানপথ |
| `world-builder-environmental-content` | সাজসজ্জা, আকর্ষণীয় জায়গা, প্রতিটি অঞ্চলের পরিবেশ |
| `ui-engineer` | মেনু, HUD, সংলাপ বাক্স, ইনভেন্টরি ও সেভ স্ক্রিন |
| `gameplay-engineer` | চলাফেরা, গেমের অবস্থা, ইনভেন্টরি, কোয়েস্ট, সেভ করা |
| `qa-tester` | টেস্ট লেখা, টেস্ট চালানো, ত্রুটির রিপোর্ট |
| `bug-fixer` | মূল কারণ সংশোধন এবং রিগ্রেশন টেস্ট |

আরও বিস্তারিত: [AGENTS.md](../AGENTS.md)।

## স্থাপত্য

Director একটি স্কিল, সাবএজেন্ট নয়, কারণ একে আপনার অনুরোধ দেখতে হয় এবং সত্যের একটিমাত্র উৎস
রক্ষা করতে হয় (`design/GAME_DESIGN.md`, `ART_DIRECTION.md` এবং আরও পাঁচটি ছোট নথি)। বিশেষজ্ঞরা
কাজের বিবরণ পান, শুধু নিজেদের ফাইলে কাজ করেন এবং রিপোর্ট ফেরত দেন; তারা অন্য এজেন্ট চালু করতে
পারেন না। গেমের বিষয়বস্তু ইঞ্জিন থেকে স্বাধীন `data/` ফোল্ডারে থাকে, তাই গল্প, লেভেল ও পরিবেশের
কাজ একসঙ্গে চলতে পারে এবং ইঞ্জিন চালু না করেই যাচাই করা যায়। সাবএজেন্ট না পাওয়া গেলে Director
নিজেই একই ধাপগুলো একে একে সম্পন্ন করে। দেখুন [ARCHITECTURE.md](../ARCHITECTURE.md)।

## পূর্বশর্ত

- Claude Code (সংস্করণ 2.1.312 দিয়ে যাচাই করা)।
- Python 3.9 বা তার নতুন সংস্করণ; বাড়তি কোনো প্যাকেজ লাগে না।
- আসল গেমের জন্য আপনার বেছে নেওয়া ইঞ্জিন, যেমন Godot 4 অথবা MonoGame-এর জন্য .NET SDK। স্কিলটি
  দেখে নেয় কী ইনস্টল করা আছে এবং কিছু ইনস্টল করার আগে আপনার অনুমতি চায়।

## ইনস্টলেশন

রিপোজিটরি ক্লোন করুন, তারপর ইনস্টলের পদ্ধতি বেছে নিন। প্রতিটি পরিবর্তন আগে `--dry-run` দিয়ে দেখে
নিন:

```bash
python scripts/install.py --scope project --project-dir ../my-game --dry-run
python scripts/install.py --scope project --project-dir ../my-game
python scripts/install.py --scope user
```

প্রজেক্ট স্কোপ `<project>/.claude/`-এ লেখে, আর ইউজার স্কোপ `~/.claude/`-এ। যেসব ফাইল আগে থেকেই আছে
এবং ইনস্টলার তৈরি করেনি, সেগুলো কখনো বদলানো হয় না। ইনস্টলেশন হালনাগাদ করতে `--update` ব্যবহার
করুন (পুরোনো ফাইলের ব্যাকআপ রাখা হয়), আর শুধু তার ইনস্টল করা অপরিবর্তিত ফাইলগুলো মুছতে
`--uninstall` ব্যবহার করুন। আপনি সরাসরি এই রিপোজিটরির ভেতরে Claude Code চালাতে পারেন, অথবা হাতে
ফোল্ডারগুলো কপি করতে পারেন। সব বিকল্প [INSTALLATION.md](../INSTALLATION.md)-তে আছে।

## দ্রুত শুরু

আপনার প্রজেক্ট ফোল্ডারে Claude Code খুলুন এবং লিখুন:

```text
/pixel-art-game-studio একটি মৌলিক, আরামদায়ক, ওপর থেকে দেখা পিক্সেল-আর্ট গেম বানাও, যাতে থাকবে একটি ছোট শহর, একটি বন, তিনটি NPC, শাখাযুক্ত সংলাপ, দিন-রাতের চক্র এবং সেভ করার ব্যবস্থা।
```

Director যুক্তিসঙ্গত ডিফল্ট বেছে নেয়, একটি ছোট ডিজাইন লেখে এবং প্রথমে একটি ছোট খেলার উপযোগী সংস্করণ
তৈরি করে। কোনো একজন বিশেষজ্ঞকে সরাসরি ডাকতে তার নাম লিখুন, যেমন `@agent-qa-tester`।

## অনুরোধের উদাহরণ

```text
/pixel-art-game-studio কুয়াশায় ঢাকা একটি জলাভূমি অঞ্চল যোগ করো, যেখানে দুটি NPC এবং দুটি সমাপ্তিসহ একটি কোয়েস্ট থাকবে।
/pixel-art-game-studio শহরটা ফাঁকা লাগছে। ছোটখাটো সাজসজ্জা আর আবিষ্কারের জিনিস যোগ করো, কিন্তু রাস্তা খোলা রাখো।
/pixel-art-game-studio এই গেমটি পরীক্ষা করো, সব উপলব্ধ টেস্ট চালাও এবং যেসব ত্রুটি আবার ঘটানো যায় সেগুলো ঠিক করো।
```

আপনি যেকোনো ভাষায় অনুরোধ লিখতে পারেন। একটি সম্পূর্ণ উদাহরণ আছে [examples](../../examples/example-game-idea.md)-এ।

## কর্মপ্রবাহ

- **গেম তৈরি**: ভাবনা থেকে সরবরাহ পর্যন্ত ১৪টি ধাপ, শুরু হয় খেলার উপযোগী সবচেয়ে ছোট লুপ দিয়ে।
- **গেম সম্প্রসারণ**: বর্তমান প্রজেক্ট পরীক্ষা করা, সবচেয়ে ছোট সামঞ্জস্যপূর্ণ পরিবর্তন করা এবং
  রিগ্রেশন যাচাই করা।
- **টেস্ট ও সংশোধন**: আসল টেস্ট চালানো, ত্রুটি জানানো এবং নিশ্চিত ত্রুটিগুলো সীমিত সংখ্যক চেষ্টায় ঠিক
  করা।
- **অ্যাসেট তৈরি**: প্রথমে শিল্প নির্দেশনা, তারপর বিবরণ, PNG ফাইল এবং প্রিভিউ।
- **রিলিজ যাচাই**: প্রমাণভিত্তিক সিদ্ধান্ত: প্রস্তুত, জানা সমস্যাসহ প্রস্তুত, অথবা এখনো প্রস্তুত নয়।

সারসংক্ষেপ: [WORKFLOWS.md](../WORKFLOWS.md)।

## টেস্টিং ও ত্রুটি সংশোধন

QA টেস্টার খুঁজে বের করে গেমের কাছে আসলে কোন কোন টুল আছে, গ্রহণযোগ্যতার মানদণ্ডকে টেস্টে রূপান্তর
করে, সেগুলো চালায় এবং গুরুত্ব, ধাপ ও প্রমাণসহ ত্রুটির রিপোর্ট লেখে। বাগ ফিক্সার প্রথমে প্রতিটি
ত্রুটি আবার ঘটায়, মূল কারণ ঠিক করে, একটি রিগ্রেশন টেস্ট যোগ করে এবং আবার যাচাই চালায়। টেস্ট দুর্বল
করা বা মুছে ফেলা কখনো অনুমোদিত নয়। এই রিপোজিটরি নিজে পরীক্ষা করতে:

```bash
python -m unittest discover -s tests -v
python scripts/validate_repository.py
```

বিস্তারিত: [TESTING.md](../TESTING.md)।

## সীমাবদ্ধতা

- এটি নিজে থেকে সম্পূর্ণ বাণিজ্যিক গেম তৈরি করে না; এমন একটি কার্যকর ভিত্তি আশা করুন যা আপনার
  মতামতের সঙ্গে বড় হয়।
- ইঞ্জিন ইনস্টল করা না থাকলে শুধু ডেটা, অ্যাসেট এবং ইঞ্জিন-নিরপেক্ষ যুক্তি যাচাই করা যায়।
- কাঠামোগত যাচাই বলতে পারে না ছবি সুন্দর কিনা বা গেম মজার কিনা; এর জন্য মানুষের দরকার।
- অনুবাদগুলো যন্ত্রের সহায়তায় তৈরি এবং মাতৃভাষীদের পর্যালোচনার অপেক্ষায় আছে।

এজেন্ট খুঁজে না পেলে `.claude/agents/` তৈরি করার পর Claude Code আবার চালু করুন। ইনস্টলার কোড 2 দিয়ে
থেমে গেলে বুঝবেন সে এমন একটি ফাইল পেয়েছে যা সে তৈরি করেনি; তার দেখানো পরিকল্পনাটি পড়ুন। আরও উত্তর
আছে [TROUBLESHOOTING.md](../TROUBLESHOOTING.md)-তে।
