## تعارف

‏Pixel Art Game Studio، Claude Code کے لیے ایک اسکل (skill) ہے جس کے ساتھ آٹھ ماہر ذیلی ایجنٹوں کی ایک ٹیم
آتی ہے۔ اس کا مقصد اصل 2D پکسل آرٹ گیمز بنانا ہے۔ آپ بس اس گیم کو بیان کرتے ہیں جس کا آپ تصور کرتے ہیں،
موجودہ نتیجے میں آپ کو کیا پسند نہیں، اور آگے کیا بدلنا ہے۔ Claude کام کی منصوبہ بندی کرتا ہے، کوڈ لکھتا ہے،
گرافکس بناتا ہے، ٹیسٹ چلاتا ہے، دہرائی جا سکنے والی خرابیوں کو ٹھیک کرتا ہے اور صرف وہی بتاتا ہے جس کی اس نے
واقعی تصدیق کی ہو۔

یہ پُرسکون کہانی پر مبنی مہمات، زندگی اور کھیتی باڑی کی سمولیشن، مکالموں سے بھرپور RPG، اوپر سے نظر آنے والے
کھوج کے گیمز اور پہیلی گیمز کے لیے بنایا گیا ہے، لیکن دوسرے اصل 2D خیالات کے لیے بھی کام کرتا ہے۔ چار حصے الگ
رکھے جاتے ہیں: **اسکل** (ہدایات)، **ایجنٹ** (ماہرین)، **اسکرپٹس** (ہمیشہ ایک جیسا نتیجہ دینے والے ٹولز) اور
**آپ کا گیم** (اس کی اپنی پروجیکٹ ڈائریکٹری)۔

## خصوصیات

- ‏Game Director کا طریقۂ کار، جو ایک مبہم خیال کو مختصر ڈیزائن اور کھیلنے کے قابل سب سے چھوٹے لوپ میں بدل
  دیتا ہے۔
- آٹھ ماہرین، جن کی ذمہ داریاں واضح ہیں، ٹولز محدود ہیں اور رپورٹ ایک طے شدہ ڈھانچے میں ہوتی ہے۔
- پروسیجرل پکسل آرٹ: JSON کی تفصیل سے اصل PNG اسپرائٹ شیٹس، میٹا ڈیٹا اور پیش نظارے بنتے ہیں۔ ایک ہی تفصیل
  سے ہمیشہ وہی بائٹس بنتی ہیں۔
- نقشوں، سجاوٹ، مکالموں، کوئسٹ، اشیا اور تراجم کے لیے ایک ڈیٹا معاہدہ، اور ایک ویلیڈیٹر جو ناقابلِ رسائی
  راستے، ناممکن مکالماتی شاخیں اور غائب ٹیکسٹ کلیدیں تلاش کرتا ہے۔
- معیار کی جانچ، جس میں سنگینی کے درجے، دہرائی جا سکنے والی خرابی کی رپورٹیں اور ریگریشن ٹیسٹ سے تصدیق شدہ
  اصلاحات شامل ہیں۔
- ایک محفوظ انسٹالر، جس میں ڈرائی رن، ٹکراؤ کی نشاندہی، بیک اپ اور احتیاط سے ہٹانے کی سہولت ہے۔

## ایجنٹ ٹیم

کل نو کردار ہیں۔ **Game Director** خود اسکل ہے اور آپ کے مرکزی Claude Code سیشن میں چلتا ہے: یہ ڈیزائن
سنبھالتا ہے، کام کی تفصیل لکھتا ہے، ہر نتیجے کی جانچ کرتا ہے اور فیصلہ کرتا ہے کہ کام کب مکمل ہوا۔ آٹھ ذیلی
ایجنٹ یہ ہیں:

| ایجنٹ | ذمہ داری |
| --- | --- |
| `pixel-artist` | فنی سمت، ایسٹ کی تفصیلات، بنائے گئے اسپرائٹ اور ٹائلیں |
| `npc-story-engineer` | کردار، شاخ دار مکالمے، فلیگ، کوئسٹ |
| `world-builder-level-design` | نقشے کی ساخت، ٹکراؤ، آغاز کے مقامات، باہر نکلنے کے راستے |
| `world-builder-environmental-content` | سجاوٹ، دلچسپ مقامات، ہر علاقے کا ماحول |
| `ui-engineer` | مینو، HUD، مکالمے کا باکس، انوینٹری اور سیو اسکرینیں |
| `gameplay-engineer` | حرکت، گیم کی حالت، انوینٹری، کوئسٹ، محفوظ کرنا |
| `qa-tester` | ٹیسٹ، ٹیسٹ چلانا، خرابی کی رپورٹیں |
| `bug-fixer` | اصل وجہ کی اصلاح اور ریگریشن ٹیسٹ |

مزید تفصیل: [AGENTS.md](../AGENTS.md)۔

## ساخت

‏Director ایک اسکل ہے، ذیلی ایجنٹ نہیں، کیونکہ اسے آپ کی درخواستیں دیکھنی ہوتی ہیں اور سچائی کا ایک ہی ذریعہ
سنبھالنا ہوتا ہے (`design/GAME_DESIGN.md`، `ART_DIRECTION.md` اور پانچ مزید مختصر دستاویزات)۔ ماہرین کو کام
کی تفصیل ملتی ہے، وہ صرف اپنی فائلوں پر کام کرتے ہیں اور رپورٹ واپس کرتے ہیں؛ وہ دوسرے ایجنٹ شروع نہیں کر
سکتے۔ گیم کا مواد انجن سے آزاد `data/` فولڈر میں رہتا ہے، اس لیے کہانی، لیول اور ماحول کا کام ساتھ ساتھ ہو سکتا
ہے اور انجن چلائے بغیر جانچا جا سکتا ہے۔ اگر ذیلی ایجنٹ دستیاب نہ ہوں تو Director وہی مراحل ایک ایک کر کے خود
مکمل کرتا ہے۔ دیکھیں [ARCHITECTURE.md](../ARCHITECTURE.md)۔

## ضروریات

- ‏Claude Code (ورژن 2.1.312 کے ساتھ جانچا گیا)۔
- ‏Python 3.9 یا اس سے نیا؛ کسی اضافی پیکیج کی ضرورت نہیں۔
- اصل گیمز کے لیے آپ کا منتخب کردہ انجن، جیسے Godot 4 یا MonoGame کے لیے .NET SDK۔ اسکل دیکھتا ہے کہ کیا
  انسٹال ہے اور کچھ بھی انسٹال کرنے سے پہلے آپ سے پوچھتا ہے۔

<!-- section: installation -->
## انسٹالیشن

سب سے آسان طریقہ یہ ہے کہ اسے Claude Code کے اندر سے پلگ اِن کے طور پر انسٹال کریں۔ اس صورت میں اسکل کا نام `/pixel-art-game-studio:pixel-art-game-studio` ہو جاتا ہے اور ایجنٹوں کے ناموں کے آگے `pixel-art-game-studio:` لگ جاتا ہے:

</div>

```text
/plugin marketplace add Rodinyamert48/pixel-art-game-studio
/plugin install pixel-art-game-studio@pixel-art-game-studio
```

<div dir="rtl">

یا پلگ اِن نظام کے بغیر:

ریپوزیٹری کو کلون کریں، پھر انسٹال کرنے کا طریقہ منتخب کریں۔ ہر تبدیلی کو پہلے `--dry-run` سے دیکھ لیں:

</div>

```bash
python scripts/install.py --scope project --project-dir ../my-game --dry-run
python scripts/install.py --scope project --project-dir ../my-game
python scripts/install.py --scope user
```

<div dir="rtl">

پروجیکٹ اسکوپ `<project>/.claude/` میں لکھتا ہے اور یوزر اسکوپ `~/.claude/` میں۔ جو فائلیں پہلے سے موجود ہیں
اور انسٹالر نے نہیں بنائیں، انہیں کبھی تبدیل نہیں کیا جاتا۔ انسٹالیشن کو تازہ کرنے کے لیے `--update` استعمال
کریں (پرانی فائلوں کا بیک اپ لیا جاتا ہے)، اور صرف ان غیر تبدیل شدہ فائلوں کو ہٹانے کے لیے جو اس نے انسٹال کی
تھیں، `--uninstall` استعمال کریں۔ آپ اسی ریپوزیٹری میں براہِ راست Claude Code بھی چلا سکتے ہیں یا فولڈرز ہاتھ
سے کاپی کر سکتے ہیں۔ تمام اختیارات [INSTALLATION.md](../INSTALLATION.md) میں ہیں۔

کسی ایک ماہر کو براہِ راست بلانے کے لیے اس کا نام لکھیں، جیسے `@agent-qa-tester`۔

## کام کے طریقے

- **گیم بنانا**: خیال سے فراہمی تک 14 مراحل، آغاز کھیلنے کے قابل سب سے چھوٹے لوپ سے۔
- **گیم کو بڑھانا**: موجودہ پروجیکٹ کی جانچ، سب سے چھوٹی مربوط تبدیلی، اور ریگریشن کی جانچ۔
- **ٹیسٹ اور اصلاح**: اصل ٹیسٹ چلانا، خرابیوں کی رپورٹ کرنا، اور تصدیق شدہ خرابیوں کو محدود کوششوں میں ٹھیک
  کرنا۔
- **ایسٹ بنانا**: پہلے فنی سمت، پھر تفصیلات، PNG فائلیں اور پیش نظارے۔
- **ریلیز کی جانچ**: ثبوت پر مبنی فیصلہ: تیار، معلوم مسائل کے ساتھ تیار، یا ابھی تیار نہیں۔

خلاصہ: [WORKFLOWS.md](../WORKFLOWS.md)۔

## ٹیسٹنگ اور خرابیوں کی اصلاح
