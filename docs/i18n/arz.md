## فكرة سريعة

‏Pixel Art Game Studio هو skill بتاع Claude Code ومعاه فريق من تمن وكلاء فرعيين متخصصين، والهدف منه إنك تعمل
ألعاب 2D أصلية بستايل البكسل آرت. إنت بس تحكي عن اللعبة اللي في دماغك، وإيه اللي مش عاجبك في النتيجة اللي
موجودة، وعايز تغيّر إيه بعد كده. وClaude هو اللي بيخطط الشغل، ويكتب الكود، ويعمل الرسومات، ويشغّل الاختبارات،
ويصلّح الأخطاء اللي يقدر يكررها، ومش بيقول غير على الحاجات اللي اتأكد منها بجد.

معمول عشان ألعاب الحواديت الهادية، ومحاكاة الحياة والمزارع، والـ RPG اللي فيها كلام كتير، وألعاب الاستكشاف
اللي بتتشاف من فوق، وألعاب الألغاز، بس ينفع كمان لأي فكرة 2D أصلية تانية. فيه أربع حاجات منفصلة عن بعض:
الـ **skill** (التعليمات)، و**الوكلاء** (المتخصصين)، و**السكربتات** (أدوات بتطلّع نفس النتيجة كل مرة)، و**لعبتك**
(في فولدر مشروع لوحدها).

<!-- section: features -->
## المميزات

- طريقة شغل الـ Game Director اللي بتحوّل فكرة مش واضحة لتصميم قصير وأصغر لفة لعب ينفع تتلعب.
- تمن متخصصين، كل واحد شغلته واضحة، وأدواته محدودة، وتقاريره ليها شكل ثابت.
- بكسل آرت معمول بالكود: مواصفات JSON بتتحوّل لـ sprite sheets بصيغة PNG بجد، ومعاها بيانات وصفية ومعاينات.
  ونفس المواصفات بتطلّع نفس البايتات كل مرة.
- اتفاق بيانات للخرايط والديكور والحوارات والمهام والحاجات والترجمات، ومعاه أداة تحقق بتلاقي المخارج اللي
  محدش يقدر يوصلها، وفروع الحوار اللي مستحيل تحصل، ومفاتيح النصوص الناقصة.
- مراجعة جودة فيها درجات خطورة، وتقارير أخطاء ينفع تتكرر، وتصليحات متأكد منها باختبارات انحدار.
- مثبّت آمن فيه تجربة من غير تنفيذ، وبيكشف التعارض، وبياخد نسخة احتياطية، وبيشيل بحذر.

<!-- section: agents -->
## فريق الوكلاء

فيه تسع أدوار. الـ **Game Director** هو الـ skill نفسه، وبيشتغل في جلسة Claude Code الأساسية بتاعتك: بيحافظ على
التصميم، ويكتب وصف المهام، ويراجع كل نتيجة، وهو اللي بيقرر الشغل خلص امتى. والوكلاء الفرعيين التمانية هم:

| الوكيل | شغلته |
| --- | --- |
| `pixel-artist` | الاتجاه الفني، ومواصفات الأصول، والـ sprites والبلاطات اللي اتعملت |
| `npc-story-engineer` | الشخصيات، والحوارات اللي ليها فروع، والعلامات، والمهام |
| `world-builder-level-design` | شكل الخرايط، والتصادم، وأماكن الظهور، والمخارج |
| `world-builder-environmental-content` | الديكور، والأماكن اللي تلفت النظر، وجو كل منطقة |
| `ui-engineer` | القوايم، والـ HUD، وصندوق الحوار، وشاشات الشنطة والحفظ |
| `gameplay-engineer` | الحركة، وحالة اللعبة، والشنطة، والمهام، والحفظ |
| `qa-tester` | الاختبارات، وتشغيلها، وتقارير الأخطاء |
| `bug-fixer` | تصليح أصل المشكلة مع اختبارات انحدار |

تفاصيل أكتر في [AGENTS.md](../AGENTS.md).

<!-- section: architecture -->
## الشغل متقسم إزاي

الـ Director هو skill مش وكيل فرعي، عشان لازم يشوف طلباتك ويحافظ على مصدر واحد للحقيقة
(`design/GAME_DESIGN.md` و`ART_DIRECTION.md` وخمس ملفات قصيرة تانية). المتخصصين بياخدوا وصف المهمة، ويشتغلوا على
الملفات بتاعتهم بس، وبعدين يرجّعوا تقرير؛ ومينفعش يشغّلوا وكلاء تانيين. محتوى اللعبة بيتحط في فولدر `data/`
مش مربوط بأي محرك، عشان كده القصة والمراحل والبيئة ممكن يتعملوا في نفس الوقت ويتراجعوا من غير ما تشغّل المحرك.
ولو الوكلاء الفرعيين مش موجودين، الـ Director بيعمل نفس الخطوات بنفسه واحدة ورا التانية. بص على
[ARCHITECTURE.md](../ARCHITECTURE.md).

<!-- section: prerequisites -->
## محتاج إيه الأول

- ‏Claude Code (اتجرّب على الإصدار 2.1.312).
- ‏Python 3.9 أو أحدث؛ مش محتاج أي حزم زيادة.
- عشان ألعاب بجد، هتحتاج المحرك اللي تختاره، زي Godot 4 أو .NET SDK عشان MonoGame. الـ skill بيشوف إيه
  المتسطّب عندك، وبيسألك قبل ما يسطّب أي حاجة.

<!-- section: installation -->
## التسطيب

أسهل طريقة إنك تسطّبه كـ plugin من جوه Claude Code. ساعتها الـ skill هيبقى اسمه `/pixel-art-game-studio:pixel-art-game-studio`، والوكلاء أساميهم هيبقى قبلها `pixel-art-game-studio:`:

</div>

```text
/plugin marketplace add Rodinyamert48/pixel-art-game-studio
/plugin install pixel-art-game-studio@pixel-art-game-studio
```

<div dir="rtl">

أو من غير نظام الـ plugins:

اعمل clone للمستودع، وبعدين اختار هتسطّب إزاي. شوف كل تغيير الأول بـ `--dry-run`:

</div>

```bash
python scripts/install.py --scope project --project-dir ../my-game --dry-run
python scripts/install.py --scope project --project-dir ../my-game
python scripts/install.py --scope user
```

<div dir="rtl">

نطاق المشروع بيكتب في `<project>/.claude/`، ونطاق المستخدم بيكتب في `~/.claude/`. أي ملف موجود قبل كده والمثبّت
مش هو اللي عامله عمره ما هيتغيّر. استخدم `--update` عشان تحدّث التسطيب (الملفات القديمة بتتاخد منها نسخة
احتياطية)، و`--uninstall` عشان تشيل بس الملفات اللي هو سطّبها ومحدش غيّرها. وتقدر كمان تشغّل Claude Code جوه
المستودع ده على طول، أو تنسخ الفولدرات بإيدك. كل الاختيارات موجودة في [INSTALLATION.md](../INSTALLATION.md).

<!-- section: quick-start -->
## ابدأ على طول

افتح Claude Code في فولدر مشروعك واكتب:

</div>

```text
/pixel-art-game-studio اعمل لعبة بكسل آرت أصلية ورايقة بتتشاف من فوق، فيها بلد صغيرة وغابة وتلات شخصيات وحوارات ليها فروع ونهار وليل وحفظ.
```

<div dir="rtl">

الـ Director هيختار إعدادات افتراضية معقولة، ويكتب تصميم قصير، ويعمل الأول نسخة صغيرة تتلعب. ولو عايز تنادي
متخصص واحد على طول، اكتب اسمه، زي `@agent-qa-tester`.

## أمثلة على طلبات

```text

/pixel-art-game-studio افحص اللعبة دي، وشغّل كل الاختبارات الموجودة، وصلّح الأخطاء اللي تتكرر.
```

<!-- section: workflows -->
## طرق الشغل

- **عمل لعبة**: من الفكرة لحد التسليم في 14 مرحلة، والبداية بأصغر لفة لعب.
- **توسيع لعبة**: تبص على المشروع الموجود، وتعمل أصغر تغيير منطقي، وتتأكد إن مفيش حاجة كانت شغالة باظت.
- **اختبار وتصليح**: تشغّل اختبارات حقيقية، وتبلّغ عن الأخطاء، وتصلّح المتأكد منها بعدد محاولات محدود.
- **عمل الأصول**: الاتجاه الفني الأول، وبعدين المواصفات وملفات PNG والمعاينات.
- **فحص قبل النشر**: حكم عليه دليل: جاهز، أو جاهز بمشاكل معروفة، أو لسه مش جاهز.

نظرة عامة في [WORKFLOWS.md](../WORKFLOWS.md).

<!-- section: testing -->
## الاختبار وتصليح الأخطاء

مختبِر الجودة بيعرف اللعبة عندها أدوات إيه بالظبط، ويحوّل شروط القبول لاختبارات ويشغّلها، ويكتب تقارير أخطاء
فيها الخطورة والخطوات والدليل. ومصلّح الأخطاء بيكرر كل خطأ الأول، ويصلّح أصل المشكلة، ويضيف اختبار انحدار،
ويشغّل الفحوصات تاني. وممنوع خالص إنك تضعّف اختبار أو تمسحه. عشان تختبر المستودع ده نفسه:

</div>

```bash
python -m unittest discover -s tests -v
python scripts/validate_repository.py
```

<div dir="rtl">

التفاصيل في [TESTING.md](../TESTING.md).

<!-- section: limitations -->
## حدوده

- مش هيعمل لوحده لعبة تجارية خلصانة؛ استنى أساس شغال بيكبر مع ملاحظاتك.
- لو مفيش محرك متسطّب، مش هيقدر يتأكد غير من البيانات والأصول والمنطق اللي مش محتاج محرك.
- الفحوصات بتاعة البنية مش هتقولك الرسم حلو ولا اللعبة ممتعة؛ ده محتاج بني آدم.
- الترجمات معمولة بمساعدة الآلة ولسه مستنية مراجعة من ناس لغتهم الأصلية دي.

<!-- section: troubleshooting -->
## لو حصلت مشكلة

لو الـ skill مش ظاهر، اتأكد إن ملف `SKILL.md` موجود في `.claude/skills/pixel-art-game-studio/`. لو الوكلاء مش
لاقيهم، اقفل Claude Code وافتحه تاني بعد ما تعمل `.claude/agents/`. ولو المثبّت خرج بالكود 2، يبقى لقى ملف هو
مش اللي عامله؛ اقرا الخطة اللي طبعها. هتلاقي إجابات تانية في [TROUBLESHOOTING.md](../TROUBLESHOOTING.md).
